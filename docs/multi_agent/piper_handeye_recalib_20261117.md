# 2026-11-17 Piper 手眼重新标定结果

已完成10个训练姿态、5个独立验证姿态的采集、逐张人工确认和离线求解。新候选已保存，尚未替换抓取配置、部署到Go2或进行真实点位/抓取验证。

## 数据与方法

- 批次：recalib20261117。固定在Go2上的RealSense D435（151222077264），ArUco ORIGINAL/ID25，黑色正方形边长142mm。操作者确认板平整、刚性固定在末端，并补充相机曾重新固定。本报告按重新固定发生在本轮采样前理解；本批次内相机与基座安装不变是采集假设，未独立量测。
- 训练：pose04、06、07、08、09、10、11、12、14、15。
- 验证：pose16、18、19、20、21，预先按角色保留，不参与拟合。
- 未收录试拍：pose01、02、03、05、13、17，原图和失败原因全部保留。
- 沿用既有core.py：图像重新检测ArUco/PnP；SDK毫米/度转换为米/弧度，姿态Rz(RZ)Ry(RY)Rx(RX)；OpenCV PARK对逆T_base_end求解eye-to-hand，再仅用训练集估计固定T_end_marker。
- 方程：T_base_end × T_end_marker = T_base_color_optical × T_color_marker。
- 正式数据及完整证据：[本轮目录](../../build/piper-handeye-recalib-20261117)。全部正式采样command_sent=false，末次核对CAN TX=0。

## 核查与限制

1. 已核实15个样本角色、人工OK决定、原图/元数据来源哈希、同期机器人数据未被替换；相机/内参/USB-CAN/姿态约定一致。图像哈希和采集时间均不重复。
2. 正逆矩阵乘积、SO(3)正交与行列式、SDK姿态重算以及全部逐样本残差复算通过。旋转激励奇异值为[0.569638, 0.370346, 0.117814]rad，通过既有求解器的非退化检查；15姿态最大相对旋转约28.05°。此检查不保证任意工作空间的精度。
3. 逐一去掉一个训练样本重算，相机位置变化最大8.684mm、旋转变化最大0.974°。仅用于敏感性检查，没有据此删样本或选择“最好”的结果，最终解仍使用完整10个训练样本。
4. 原manual04历史独立验证RMS为13.164mm/6.284°，本轮为3.315mm/0.704°。两者来自不同批次和不同相机安装状态，只能比较各批次内部一致性，不能据此评价同一安装下哪个矩阵更接近真值，也不能把差异归于某个算法错误。用户确认相机重新固定，因此新R与原manual04的15.341°差异、与当前手动修正抓取R的5.642°差异属于不同安装状态的参数差，不作为错误证据。相对当前抓取配置，相机位置差[-57.471,+45.245,-111.247]mm；这些差值不作为追加调参量，新安装应使用新测得的完整刚体变换。
5. physical_validation=NOT_PERFORMED。板的实测平整度、固定关系是否在整个过程完全不变、SDK末端与实物法兰/TCP的对应仍未独立验证；本轮未做TCP标定、未做实物点位或抓取验证。历史负夹爪开口反馈原样保留，未解释为真实开口或修改零点。
6. 本轮只调用既有采集/求解工具，未修改产品代码、库版本或外参配置；没有构建/提交/部署，也没有发送运动命令。
