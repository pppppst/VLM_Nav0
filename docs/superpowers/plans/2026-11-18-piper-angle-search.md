# Piper 抓取角度枚举实施计划

**Goal:** 大模型仅选目标位置，启发式枚举俯仰和水平朝向，按顺序找到首个完整路径可行方案。
**Architecture:** 复用现有SAM/深度定位、带限位IK与分段规划。默认semantic配置启用角度表；固定角度CLI保留原手动语义。默认yaw偏移0、±30、±60、±90、±120、±150、180°；每个yaw尝试pitch40、30、50、20、60、10、70、0、80、90°。角度表及顺序是本轮实现选择；用户已明确选择俯仰＋水平朝向。候选TCP位置不变，姿态由程序枚举；默认semantic-camera-avoid预抓/入口各沿接近方向反向100mm；semantic.json未配置额外入口时仍为0。不是全SO(3)穷举或碰撞规划。
**Tech Stack:** 既有NumPy/SciPy/OpenCV/Plotly，无新依赖。

范围：semantic.py去掉模型提示里的上方抓取要求，保存可见点在基座XY平面的凸包用于不同夹爪朝向的宽度；geometry.py枚举姿态、复用完整路径检查并保存每个候选结果；main.py默认入口及逐候选诊断；report/cloud_report显示实际采用的方向、路径与搜索记录；两份启发式配置、相关测试/文档/安装入口。GraspNet及旧参考模式保持既有行为。关节限位、IK判据、速度/力矩不变。转向后的宽度须适配现有open_ready_mm/open_mm及SDK0..100mm指令范围，否则WAIT_WIDTH并继续下一角度；不新增任意容差。全部拒绝维持可恢复等待。完整搜索结束仍由原新鲜度与初始关节检查决定是否可执行。只实施/构建/离线验证，不自行新抓取。
