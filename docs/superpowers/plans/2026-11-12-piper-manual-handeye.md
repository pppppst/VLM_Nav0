# Piper 手摆姿态与逐张确认实现计划

用户已选择手动摆姿态、每姿态回传图片，延续非运动配置与部署授权。本轮不发送示教/运动/回放命令，由操作者按物理按钮操作。板尚未固定，先做非正式看图。

设计：扩展现有只读标定采集，新增review保存原始图像及同期位姿候选；板未检出/反馈缺失/不静止时仍保存图片和失败原因。正常、明确的示教记录状态可以记录静止反馈，故障与回放不能当有效样本。原standalone/SDK及异常处理不变。新增本机入口用SSH调用review并拉取到Pictures，人工approve仅收录当时已声明固定、数据有效的同一张图片和同一组位姿，不重新拍照。记录source hash与人工确认；不可覆盖旧样本。没有新依赖、界面服务或持续RGB订阅。

涉及：handeye/capture.py、handeye/review.py、piper_handeye.sh的入口复用、独立piper_handeye_review.sh、tests/test_capture.py与新test_review.py、handeye/README.md；双端部署、哈希和交接。原采集/求解接口保持。实际项目在VLM_Nav外且不是Git仓库，使用build内独立stage和修改前哈希；不创建无意义ROS worktree、不提交。
