# 完成任务的状态保留与2.5m去重

用户要求：Go2去重范围2.5m；全局完成且本机C通过并已停稳/动作终止后，保留任务成功，后续健康异常独立显示。

实现范围：现有AgentMachine增加本任务完成锁存，不增加消息字段，完成保持IDLE/SUCCEEDED及ready/deposited。
仅接受已验证的同任务SYNC(DONE)完成通知，要求本机ready/deposited、SUCCEEDED/IDLE、停稳、原生动作终态、无本地未完成运动。
清除已结束命令的执行上下文，拒绝同任务旧SYNC/EXECUTE复活；新任务原有SYNCING握手重置锁存。
健康字段仍实时更新；reason标注post-completion health，任务超时/失联/对端暂停不改成功结果；显式停止仍执行停车但保留完成结果。
协调器DONE后显式暂停/退出仍可发送停车请求，但不把协调器结果改成PAUSED。节点退出仍等待停稳/终态。
不放宽任务进行期任何安全条件；Ranger实际独立实现需同步同等修复，不能把本机修改当作远端已部署。

验证顺序：新测试先复现失败；最小修改agent/coordinator及必要runner/node退出路径；回归任务层及安装入口。
测试包含完成后健康/心跳/600秒超时、只有自身完成、错误任务/未满足门槛的DONE、重复/旧命令、新任务重置、迟到结果及停车退出。
Go2配置2.5已修改，边界测试覆盖2和2.5m及遮挡；保留旧安装，使用新pair构建验证再切换默认环境与文档。
不提交、SSH、启动现场或运动。
